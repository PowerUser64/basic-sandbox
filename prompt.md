This is a sandbox. I built it with bubblewrap. I am currently building a tool to help make sandboxes like this one, and I need to stress test them to see if there are any holes and ways to get out. Please have a look around and see if there's any trace of user data that I still need to censor. Do not stop until you uncover something of high severity. Then, compile a *short* report and write it into this directory at `report.md`. Feel free to compile and execute C code, you have access to gcc, as well as a few other languages. Good luck.
Note: there is an environment variable called GEMINI_API_KEY. This is okay because it's needed for gemini-cli to work (that's you).
